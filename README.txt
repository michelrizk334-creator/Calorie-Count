CALORIE COUNT v14 — OFFLINE INSTALLABLE APP

This build contains the complete 111-food Support List from the Excel workbook and all v13 features.

IMPORTANT:
- The app works offline after it has been installed from a normal HTTPS website.
- iPhone/iPad: open the hosted app in Safari > Share > Add to Home Screen.
- Android: open the hosted app in Chrome > Install app / Add to Home Screen.
- iOS does not install an app directly from a ZIP/HTML attachment. The folder must first be hosted on HTTPS.
- All tracking data is stored locally on the device/browser.
